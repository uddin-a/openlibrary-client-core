# Open LIbrary API Client

## Description

This is an unofficial [openlibrary api](https://openlibrary.org/developers/api) client implement in Typescript
to be used in Javascript / typescript projects.

## Implimentation

Currently implemented APIs from [openlibrary.org](https://openlibrary.org).

- [] [Book Search](https://openlibrary.org/dev/docs/api/search)
- [] [Work & Edition](https://openlibrary.org/dev/docs/api/books)
- [] [My Books](https://openlibrary.org/dev/docs/api/mybooks)
- [] [Authors](https://openlibrary.org/dev/docs/api/authors)
- [] [Subjects](https://openlibrary.org/dev/docs/api/subjects)
- [] [Search inside](https://openlibrary.org/dev/docs/api/search_inside)
- [] [Partner](https://openlibrary.org/dev/docs/api/read)
- [] [Covers](https://openlibrary.org/dev/docs/api/covers)
- [] [Recent Changes](https://openlibrary.org/dev/docs/api/recentchanges)
- [] [LIsts](https://openlibrary.org/dev/docs/api/lists)
- [] [History](https://openlibrary.org/authors/OL236414A.json?m=history)
